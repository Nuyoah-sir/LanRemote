## 本机环境实测（修正：我第一版读错了）

- 实测 `Win32_OperatingSystem.Caption` = **Microsoft Windows 11 专业版**，Version 10.0.26200，Build 26200，
  DisplayVersion 25H2 → 本机是 **Windows 11 25H2**，不是 Windows 10。
- **陷阱**：`HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ProductName` 在 Windows 11 上仍是
  `Windows 10 Pro`。我第一版只读了这个值就写下「Windows 10 Pro 25H2 / build 26200」——**这个组合不成立**。
  判系统版本必须用 `Win32_OperatingSystem.Caption`，不能用这个注册表值。
  （这是外部模型纠正我的，我用 CIM 复测确认它对。）
