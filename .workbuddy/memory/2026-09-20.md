## 本环境的几个坑（下次别再踩）

1. **PowerShell 工具在本机会话里不回显输出**（返回空），`powershell.exe` 从 Bash 调用会被安全策略拦截
   → 需要 Windows 侧操作时，优先找「不需要 PowerShell」的替代路径（例如用 Python 解压 zip）。
2. **`reg.exe` 被安全黑名单拦截**，不要尝试用它查注册表，也不要绕道。
3. **`.NET 10` 的 `dotnet new sln` 默认生成 `.slnx`**，规格要求 `.sln` 时必须加 `-f sln`。
4. Git Bash 里给 PATH 追加路径要写成 `/c/Users/...`，写 `C:\...` 不生效。
5. **后台程序用 `(cmd &)` 会被回收**：做「启动两个进程」这类验证时，第二个进程看不到第一个，
   会得到假的失败结论；必须在同一条命令里用 `$!` 拿 PID 并 `kill -0` 确认存活。
6. App 项目里有 3 个文件必须显式 `using System.IO;`（XAML 编译路径下隐式 usings 少了 IO），
   Core 项目不需要。删掉会编译失败。

## M1.1 Security Hardening（同日，M1 审计修复）

修了 5 件事：

1. 证书私钥导入 `PersistKeySet|Exportable` → **`EphemeralKeySet`**（ADR-016 标记 superseded，新增 ADR-018）。
   相关 P-256 测试改为只用公钥确认曲线；保留「重载后签名 + 公钥验签」测试。
   **未关闭风险**：Windows SslStream 服务端用 ephemeral 私钥是否可靠没有实测，
   强制要求 M3 补真实握手集成测试，在此之前不得凭猜测改回 PersistKeySet。
2. `DpapiSecretVault.UpdateAsync` 改 **copy-on-write**：克隆 working copy → 只在 working 上改 →
   先落盘成功 → 才替换 `_cached`。`PersistCoreAsync` 开头 `ThrowIfCancellationRequested()` 让取消确定性。
   新增 `SecretBundle.Clone()`。ADR-019。
3. 秘密 byte[] 清零：`SecretGenerator.NewAccessKey`、PFX 导出缓冲、PFX 导入缓冲、
   `MainViewModel.RegenerateAccessKeyAsync` 的轮换结果。string 不可变无法清零，诚实记录。
4. 证书 bundle 状态 **fail closed**：PFX 与口令恰好只有一个存在 → `InvalidDataException`，
   不静默重签证书（否则指纹会静默改变）。ADR-020。
5. `SecretFile.UnpackProtected` 长度校验改**严格相等**（原来是 `<` 即放过），
   并校验 payload 内 `bundle.Version`。

结果：build PASS 0 警告 0 错误；test **189 passed / 0 failed**（Security 46 → 60，+14）。
已 `git init` 并完成首个基线提交 `664e558`（97 文件），`.gitignore` 确认屏蔽 bin/obj/secrets.bin/logs/pfx。

## M1.3 ECDSA Certificate KeyUsage Fix（同日，M1 最后一次修改）

ECDSA P-256 end-entity 证书此前声明 `DigitalSignature | KeyEncipherment`。
RFC 5480 对 `id-ecPublicKey` 的 end-entity 证书只允许 digitalSignature / nonRepudiation /
keyAgreement；keyEncipherment 是 RSA 密钥传输语义，在 EC 证书里声明属 profile 违规。
改为 `new X509KeyUsageExtension(X509KeyUsageFlags.DigitalSignature, critical: true)`。
serverAuth EKU 保留；P-256 / SHA-256 / EphemeralKeySet / 指纹算法 / PFX+DPAPI / 5 年 / CA=false 全未动。

新增 3 条测试：KeyUsage 恰好等于 DigitalSignature、组合 profile（P-256+CA=false+KU+EKU+id-ecPublicKey）、
重载后 KeyUsage 不变。test **200 passed / 0 failed**。Last code commit `9e75fce`。

**本机开发 identity 已手工重置**（备份到 `backups/secrets.bin.pre-m1.3-reset.bak`）：
设备码 QPKE-2CPC → **M5WC-14GX**，指纹 3A3D791A → **89A5C10E**。
这是 pre-release 开发身份处理，production code 里**没有**加任何静默自动换证逻辑（ADR-021 明确列为硬约束）。
